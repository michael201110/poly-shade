# PolyShade 0.3.2

Motion blur now follows movement relative to the camera. Static track geometry uses depth reconstruction and the previous camera projection. Opaque native cars use their actual previous object transforms in a full-resolution velocity pass: body translation, turning, suspension and wheel rotation are tracked separately. A car held steady by the chase camera therefore stays sharp; a moving car seen by a fixed camera acquires blur. There is no focus ellipse or artificial boost for distant scenery.

The velocity pass reuses native geometry in a separate scene, without changing game materials or hierarchy. Its fragments must match the existing scene depth, so bridges and walls occlude it. One reusable full-resolution target and seven small draws for the standard car are added while blur is enabled. Transparent replay ghosts are excluded because they do not write the opaque scene depth. Custom moving objects without the native car structure still use camera-only motion.

Exposure is now expressed directly in milliseconds: 20 ms by default, adjustable from 0 to 64 ms. The old shutter control maxed out at 16.7 ms. Saved legacy overrides are converted to that same exposure duration; reselect a preset to apply the new defaults. Frame interval normalization keeps exposure stable across frame rates. Four to sixteen centered samples plus the center adapt sampling density to trail length. The trail cap is 32 pixels by default and can be raised to 64. The sky responds to camera rotation, not translation. Camera cuts, scene changes, projection changes and frame gaps over 120 ms reset motion history. No temporal image accumulation or synchronous GPU readback occurs in the shipped effect.

The depth rejection now predicts inverse depth along the surface's screen-space slope. The previous fixed tolerance treated a receding road as a depth discontinuity, rejecting long shutter samples and leaving the road effectively sharp. Inverse depth is linear across a projected plane, so the revised test accepts taps on the same road surface while rejecting samples across actual occluder boundaries. Derivatives are computed before divergent pixel early-outs. Car/object mask boundaries remain protected.

Clear Day, Soft Overcast, Golden Hour and Capture use 20 ms / 32 pixels. Vanilla and Golden Hour Lite leave blur off. Settings remain under Post Processing. Optical effects are composited after blur. Zero exposure releases the car velocity resources instead of allocating an unused target.

Validation: `npm run check` covers chase-camera cancellation, moving cars with a fixed camera, wheel transforms, ghost exclusion and camera-cut reset. `npm run verify:replay` exercises the actual Summer 2 #1 replay through PML 0.6.3 and reads the velocity target only in the test harness to compare corrected car motion against the old camera-only estimate. `npm run verify:live` checks presets, renderer state restoration, resource lifecycle and the existing effects.

The 53 unit/integration tests and the actual Summer 2 #1 replay passed. A GPU regression using the shipped blur function on a striped receding plane changed every sampled pixel and reduced contrast energy to 0.00346 of the sharp image; a nearer opaque foreground surface introduced zero colour leakage into the background. The replay harness can capture blur-off and maximum-exposure outputs from the exact same frame using `POLYSHADE_COMPARE_BLUR=1`; maximum blur changed 11.2% of pixels by more than eight RGB levels in one captured frame, with the car retaining its actual screen-relative motion. Images/reports are under `%TEMP%/polyshade-blur-after/` for this pass. Replay trajectories vary with capture timing, so before/after runs are not compared as identical frames.

The preceding full PML lifecycle suite passed with zero new shader programs and zero effect target allocations during braking. This update changes sampling and shutter settings, adds no render targets, and leaves that resource retention path intact. These are validation observations on this machine, not a guarantee of frame rate on other GPUs.
