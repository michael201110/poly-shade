# PolyShade 0.6.0-fsr31.5 - upscale comparison and native grade gate

This version adds an exact early gate to the native grade's atmospheric haze. It computes camera-space distance first and skips direction, tint and exponential work when the pixel is before the configured haze start. Beyond that distance, the haze expression is unchanged. Rendering only; no scene, replay timing, physics or training behavior changes.

## FSR 3.1 SR and SGSR2 at 4K output

Matched live Summer 1 runs used the same PolyShade 0.6.0-fsr31.5 bundle, 3840x2160 output, 50% internal scale, Golden Hour/cinematic settings, T500 and 15-second moving gameplay harness. Timestamps were enabled in both captures. These are actual rendered-frame submissions, not RAF callback rates.

| Upscaler | Effective FPS | Render interval p50 / p95 / p99 | GPU work p50 / p95 | T500 utilization | Errors |
| --- | ---: | ---: | ---: | ---: | ---: |
| FSR 3.1 SR | 28.50 | 33.5 / 48.6 / 50.1 ms | 32.77 / 35.32 ms | 100% | 0 |
| SGSR2 Compute | 59.97 | 16.7 / 18.5 / 19.6 ms | 9.11 / 10.42 ms | 75-92% | 0 |

SGSR2 is the clear performance choice on this T500: it delivered about 2.1x FSR's submitted FPS in the matched run, with much lower GPU time. Frame generation was off. This is a performance comparison; moving-image quality was not compared here.

A separate 60.28-second unprofiled SGSR2 run on the same .5 bundle kept the moving 4K path at **59.984 FPS** (p50/p95/p99/max interval 16.7/18.3/19.3/28.5 ms), with zero errors and all cinematic effects enabled. The p95 and maximum show occasional missed-refresh intervals despite the near-60 average. Frozen-scene error and temporal stability evidence is in [the 4K60 verification](verification/4k60-sgsr2-main.md) and [temporal stability report](temporal-jitter-stability.md).


## Native 4K profiling

The 0.6.0-fsr31.5 Native run reached 46.17 FPS. GPU work measured 17.17 ms median and 18.28 ms p95, just above the 16.67 ms budget for 60 FPS. T500 use was 98-100%.

| Pass | GPU p50 | GPU p95 |
| --- | ---: | ---: |
| Scene | 4.72 ms | 5.11 ms |
| Grade | 5.18 ms | 5.77 ms |
| Finish | 1.90 ms | 2.29 ms |
| AO + horizontal/vertical filters | 2.75 ms | 3.08 ms |
| Sun rays | 0.79 ms | 0.85 ms |
| Total | 17.17 ms | 18.28 ms |

The atmosphere gate's earlier isolated 0.6.0-fsr31.4 comparison found grade p50/p95 13.17/18.02 ms before versus 5.37/14.94 ms after; total p50/p95 23.92/30.08 ms versus 20.25/28.77 ms. A 60 Hz capped comparison remained about 44.5 FPS on both versions, so that capture did not show an end-to-end capped throughput increase. The fresh 0.6.0-fsr31.5 profile continues to identify grade and scene as the largest native passes.

A direct 3840x2160 WebGPU output comparison of the original and haze-gated grade used identical inputs and found 0 different bytes across 66,355,200 output bytes. Both shader variants compiled successfully. This supports exact output preservation for the compared frame; it does not claim every driver/compiler must produce bit-identical results for every possible input.

## Follow-up candidate rejected

A second exact candidate moved center depth/position acquisition into the no-motion return path so haze, lens and volumetric code could share it. It matched the baseline byte-for-byte on stationary and moving-velocity inputs (66,355,200 bytes per comparison). A controlled same-input 4K pass benchmark improved median time only from 2.56 ms to 2.42 ms (-0.14 ms); that is below the project's ~1 ms priority threshold, so the candidate was discarded and is not in the release.

The T500 remains the limiter for native 4K. SGSR2 at 50% is already near 60 FPS, while native still needs a larger exact saving. The next priority remains architectural work on scene rendering or the full-resolution grade; sub-millisecond shader cleanup is secondary.
