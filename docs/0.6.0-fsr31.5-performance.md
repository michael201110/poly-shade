# PolyShade 0.6.0-fsr31.5 — upscale comparison and native grade gate

This version adds an exact early gate to the native grade's atmospheric haze. It computes camera-space distance first and skips direction, tint and exponential work when the pixel is before the configured haze start. Beyond that distance, the haze expression is unchanged. Rendering only; no scene, replay timing, physics or training behavior changes.

## FSR 3.1 SR and SGSR2 at 4K output

Matched live Summer 1 runs used PolyShade 0.6.0-fsr31.3, a 3840×2160 canvas, 50% internal scale, Golden Hour/cinematic settings, the same T500 and a 15-second moving gameplay harness. These are actual rendered-frame submission rates, not RAF callback rates.

| Upscaler | Effective FPS | Render interval p50 / p95 / p99 | T500 utilization | Errors |
| --- | ---: | ---: | ---: | ---: |
| FSR 3.1 SR | 28.13 | 33.6 / 48.9 / 50.0 ms | 100% | 0 |
| SGSR2 Compute | 59.97 | 16.7 / 18.3 / 19.6 ms | 81% | 0 |

SGSR2 also sustained 59.95 FPS over 60 seconds (p95 18.7 ms, p99 20.2 ms; a 31.7 ms worst interval). A separate uncapped run on 0.6.0-fsr31.4 reached 79.25 FPS at 50% scale, with p50/p95 render times of 12.5/17.2 ms. FSR is currently the slower path on this T500; frame generation was off. This performance comparison does not establish which mode has better moving-image quality.

## Native 4K profiling

On 0.6.0-fsr31.4, uncapped Native reached 39.73 FPS (p50/p95 rendered interval 24.7/35.0 ms) with the T500 at 98–100% use. The exact-gate candidate reached 47.14 FPS in its uncapped run (20.5/30.2 ms p50/p95). Under the 60 Hz cap both versions remained near 44.5 FPS, so this shader optimization did not improve capped throughput in that capture.

The timestamp-query profiles show where the candidate helped: native grade GPU p50/p95 changed from 13.17/18.02 ms in the baseline profile to 5.37/14.94 ms in the candidate profile; total profiled GPU p50/p95 changed from 23.92/30.08 ms to 20.25/28.77 ms. The runs use different motion samples and are not a perfectly paired A/B; use them as pass diagnostics, not a guaranteed frame-rate delta. The large reduction is consistent with avoiding haze work on pixels that cannot contribute haze.

A direct 3840×2160 WebGPU output comparison of the original and gated grade used identical inputs and found 0 different bytes across 66,355,200 output bytes. Both shader variants compiled successfully. This supports exact output preservation for the compared frame; it does not claim every driver/compiler must produce bit-identical results for all possible inputs.

The T500 remains the limiter for native 4K. This change narrows the grade cost, while SGSR2 50% is already close to 60 FPS. The next large native target is scene rendering and the remaining full-resolution post passes; sub-millisecond cleanup stays lower priority.
