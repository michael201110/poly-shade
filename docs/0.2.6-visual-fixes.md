# PolyShade 0.2.6 visual fixes

This update addresses shadow artifacts that appeared as square black patches on distant scenery, weak shadow separation where multiple objects overlap, and sun rays that were too hard to see.

The mod now limits its local shadow receivers and casters to twice the configured gameplay shadow coverage. Distant geometry no longer samples the tightly focused shadow map, which avoids exposing its finite resolution as large blocks near the horizon. Original mesh shadow flags are restored on unload and when shadows are disabled. This is a distance cull over the existing scene mesh list; it adds no render pass.

Shadow strength defaults to 0.84 and the soft-shadow filter uses its maximum radius. Golden Hour sun-ray strength is 0.20, up from 0.14; Capture is 0.30, up from 0.24. These changes reuse the existing shadow and ray passes.

The existing 0.2.4 and 0.2.5 release bundles remain immutable. The new root manifest points PolyTrack 0.6.3 to 0.2.6.
