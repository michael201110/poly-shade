# PolyShade 0.5.6 — stability rollback

PolyShade 0.5.6 restores the renderer source from the known 0.5.4 build after the 0.5.5 release was reported to cause severe input lag and frame drops, including at resolutions below 1080p.

The 0.5.5-only runtime changes removed in this rollback were:

- Quarter-resolution ray integration.
- The SGSR2 scale uniform and corresponding 96-byte parameter buffer.

This is a containment release, not a verified root-cause fix. The reports do not yet prove which change caused the regression. Check gameplay with 0.5.6 first; investigate the two changes separately before considering them again. Replay, physics and training code were not changed.

The moving replay smoke profile at 1280×720 loaded WebGPU without errors and measured 9.18 ms median GPU work. Its headless browser frame interval was 33.2 ms median; this is a smoke benchmark, not proof of live-game input latency or frame rate. Live confirmation is still needed.
