# PolyShade 0.2.5 optimization

This release reduces rendering work and removes observed allocation/compilation stalls without lowering the 0.2.4 presets. Scene scale, shadows, AO samples, environment resolution, cloud shapes, lighting, grading, FXAA and shaft resolution remain unchanged. Radial occlusion edges are filtered more smoothly.

## What changed

- The original native sun previously had zero intensity but still rendered a shadow map alongside PolyShade's sun. It now stops casting shadows and contributing to shader light arrays. Native CSM keeps all its cascades. Original visibility, lighting and shadow settings restore on disable.
- Configured ray, volumetric and visibility buffers are initialized ahead of their first appearance and retained through offscreen/full/partial occlusion. Disabling features releases them. Skipped effects still skip their rendering passes.
- Brake-light and optional post shaders are submitted through the game's public `compile()` API, one job per frame, when parallel compilation is supported. Hidden lamp parents are temporarily exposed for compilation, then restored. Car replacement triggers warming even when mesh/light counts stay the same. Idle lamps remain absent from gameplay lighting. Native CSM's scene shaders retain their own compilation lifecycle; only post shaders are warmed in that mode, preventing cleanup errors from its mutable shader hooks.
- A small filtered sun aperture replaces repeated binary full-frame depth sampling and Gaussian evaluation in the ray loop. The same 48 steps and strengths remain; negligible samples beyond the aperture are skipped. Existing shaft filtering remains.
- Fullscreen passes use a single oversized triangle and skip redundant clears. Resolved settings, unchanged material synchronization and hidden diagnostic text avoid repeated work. Whole-track bounds are calculated only for fallback fog.
- Identical directional shadow views can reuse their maps. Exact transform, morph, geometry, coverage, light and topology checks invalidate them; driving prioritizes changed car/light transforms and avoids unnecessary whole-track validation. Continuously moving suspension still updates shadows every frame. No shadow resolution or update-frequency reduction is used.
- Native brake lamp materials retain the handle PolyTrack updates, preserving emissive animation and surface illumination.

## Matched measurements

The immutable 0.2.4 bundle and final 0.2.5 bundle were tested in actual PolyModLoader/PolyTrack 0.6.3, using headless Microsoft Edge on Windows at 1280 x 720. Each scenario warms for two seconds, then samples about eight seconds. CPU measurements include controller updates and rendering; GPU queries are asynchronous. Driving uses actual input, braking repeats acceleration/braking, and a graphics-only occluder exercises changing sun visibility. Cloud time is frozen only in this comparison harness.

Average milliseconds per frame:

| Scenario | CPU 0.2.4 | CPU 0.2.5 | GPU 0.2.4 | GPU 0.2.5 |
| --- | ---: | ---: | ---: | ---: |
| Lite stationary | 4.82 | 4.24 | 7.82 | 6.26 |
| Golden Hour stationary | 6.52 | 5.27 | 11.49 | 8.55 |
| Capture stationary | 10.17 | 5.00 | 13.11 | 8.65 |
| Capture driving | 12.08 | 8.54 | 14.46 | 11.18 |
| Capture braking | 10.33 | 6.79 | 11.79 | 9.77 |
| Capture partial sun | 7.06 | 5.82 | 13.62 | 9.99 |
| Capture changing occlusion | 7.53 | 7.49 | 11.95 | 10.60 |

Capture driving reduced average CPU time by 29% and GPU time by 23%; stationary Capture GPU time fell 34%. Worst observed CPU submission during braking fell from **1,434.5 ms to 25.9 ms**. Driving, braking and changing occlusion now allocate/dispose **zero** targets and create **zero** shaders during measurement; baseline allocations were 26, 3 and 30, and baseline driving/braking created 3/13 shaders.

No frame intervals exceeded 50 ms in the final candidate scenarios. Some smaller frame gaps remain during driving; this is a short measurement on one machine, not a guarantee that every GPU, track or browser will have no stutters. Parallel shader warming is unavailable when the driver lacks the extension. Changing presets/environment resolution, loading tracks and resizing still require setup work. Native CSM keeps its required shadow rendering cost and native scene compilation behavior.

The full numerical results, sample counts, percentiles and frame-gap counts are in [0.2.5-benchmark.json](0.2.5-benchmark.json).

## Visual and compatibility verification

Static screenshot comparisons preserve the sky, clouds, mountains, ground, road and shadows. Excluding the moving car and rotating checkpoint arrow, Golden Hour and Capture differed by at most one display colour value out of 255. The sun-aperture change preserves the existing shaft appearance while smoothing its binary mask. An attempted sky draw-order optimization was rejected because it covered PolyTrack's distant ground plane; original sky ordering remains.

`npm run check` passes 44 tests covering settings caching, exact shadow invalidation/restoration, suppressed native lights/CSM, material preservation, lamp shader warming after car replacement, early target initialization, occlusion buffer reuse and failure cleanup, alongside existing lifecycle/rendering tests.

The full live harness checks preset targets, resized buffers, disable/F7 restoration, native brake illumination, camera switching, driving/restart, multiple tracks, four native CSM cascades, sun/cloud coherence, open/partial/blocked/behind-camera sunlight, arch occlusion, shader failures and GL errors.

An additional instrumented native-shadow test performs three CSM/local-shadow switches and F7 cycles with a GL error check after every command. It passes with zero errors. Scene warming with native CSM was rejected during verification; the compatibility guard preserves its shader hooks.

## Reproduce

Run sequentially with no other benchmark browser running:

```powershell
npm run check
$env:POLYSHADE_OPTIMIZATION = '1'
$env:POLYSHADE_RELEASE = '0.2.4'
$env:POLYSHADE_OUTPUT = '/polyshade-opt-before'
node scripts/verify-live.mjs
$env:POLYSHADE_RELEASE = '0.2.5'
$env:POLYSHADE_OUTPUT = '/polyshade-opt-after'
node scripts/verify-live.mjs
Remove-Item Env:POLYSHADE_OPTIMIZATION
Remove-Item Env:POLYSHADE_RELEASE
$env:POLYSHADE_OUTPUT = '/polyshade-0.2.5-live'
node scripts/verify-live.mjs
```

Artifacts go to the selected folder under `%TEMP%`. Instrumentation and benchmark fixtures are absent from the release bundle.
